# Contributor conduct

Contributors should provide respectful, evidence-based technical discussion, welcome constructive disagreement, and avoid harassment, discrimination, threats or publication of private information. Report concerns privately to the repository maintainers using contact details in their public GitHub profiles. Do not place sensitive incident details in a public issue. Maintainers may moderate discussions or restrict contributions to protect participants.

This independent GPL-3 pipeline is maintained in the Katsevich Lab repository; nf-core community membership or enforcement jurisdiction is not implied.
