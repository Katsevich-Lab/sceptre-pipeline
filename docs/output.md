# Output reference

The canonical detailed output contract is [outputs.md](outputs.md). It distinguishes scientific tables/native objects/public plots, complete-family correction, failed QC, provenance and execution reports. See [scientific delivery](scientific-delivery.md) for portable HDF5 reopening and complete/omitted/failure report states. `pipeline_info/software_versions.yml` records software-version topic values; per-stage locks and manifests additionally bind installed hashes, dependencies, source and RNG.
