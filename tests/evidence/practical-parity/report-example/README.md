# Synthetic scientific report examples

These are **synthetic** screens generated by `demo/make-input.R`. They contain
no real experimental, participant or private data.

Open `complete/report.html` for the full scientific report, `partial/report.html`
for preparation with all three scientific families omitted, and
`failure/report.html` for a deliberately failed renderer with saved evidence
links. These are scientific reports, distinct from Nextflow execution reports
and runtime/memory benchmark reports. Each state retains complete local assets,
tables, requested configuration, provenance, native object and reopen helper.

The screen has 320 imported cells, 315 retained cells, eight guides and eight
response features. Workflow seed: 271828. The complete report contains eight
calibration rows, two positive-control rows and five discovery rows (four finite
p-values, one failed-QC row and two package significance flags under BH,
alpha 0.1). Median calibration raw p-value: 0.488. Positive-control tables
contain their actual p-values/effects and deliberately have no added
across-pair significance or inferred hit rate.

Qualification used schema-7 `sceptre` 0.99.0 in the selected local isolated R
library, R `4 6.0 aarch64-apple-darwin23`, installed-package identity
`c35ce0113c9eab866225fc0c1bc524e87e0afcefd49b2546da960396608647be`.
Selected package source commit: `1e4d5459ab229255694f9217d7cd4ed51a4bf1b8`;
archive SHA256: `f41a8fb7e1bc10366e8efcc7a31644d4c8356bc4eca8adda9ca949c951de4fb4`.
Complete runtime/dependency identity is in each `manifest.rds`; exact public
value checks and renderer identities are in `report-value-checks.rds`.
The final renderer SHA256 is
`8065257d9414ed1b6980172aff566fadcf900b41ef91d103e7e957a7465e4b62`.

The value fixture passed `tests/test_report_presentation.R`; only presentation
styles/wording were subsequently rerendered from frozen values. The value
receipt retains both the initial and final renderer hashes. No scientific
analysis was rerun for that visual refinement. Screenshot hashes and final
HTML hashes are recorded in `../visual/visual-review.json`.

Manual local Chrome review covered complete, omitted and presentation-failure
states at actual CSS viewports 1440×1000 and 390×844, including visible public
plots, internal figure/table scrolling, no page-wide horizontal overflow,
navigation, readable text and preview filtering. This is neither hosted browser
coverage nor a full-scale/cluster/performance/release qualification. A small
synthetic calibration family does not establish scientific calibration for a
real screen. The deliberately failed renderer remains recorded as failed even
though saved scientific stages are valid.
